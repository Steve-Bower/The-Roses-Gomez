# The Roses Gómez Barbershop

Static website for [RosesGomez.com](https://rosesgomez.com).

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Hosting

The site is built for GitHub Pages from the `main` branch root. The `CNAME` file points the custom domain to `rosesgomez.com`. After the repo is live, point the domain’s DNS to GitHub Pages.
